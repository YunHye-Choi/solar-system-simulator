# 태양계 여행

실제 행성 크기와 거리를 반영한 태양계를 탐험하는 시뮬레이터입니다. 행성 표면을 걷거나 천체 사이를 비행하고, 주요 착륙 지점을 방문하며, HUD와 미니맵으로 주변을 살펴볼 수 있습니다.

최신 브라우저에서 바로 실행되며 WebGL 2를 사용합니다. 별도의 빌드 과정이나 런타임 의존성은 없습니다.

## 실행

최신 브라우저에서 `index.html`을 열거나 다음 명령으로 프로젝트 폴더를 HTTP 서버에 띄웁니다.

```sh
python3 -m http.server 8765
```

그런 다음 <http://localhost:8765>에 접속하세요. 화면 오른쪽 위의 언어 버튼으로 영어와 한국어를 전환할 수 있으며, 선택한 언어는 브라우저에 저장됩니다.

## 파일 구성

- `index.html` — 페이지 구조, 스타일, 언어 전환 버튼
- `i18n.js` — 영어·한국어 UI 번역
- `main.js` — 궤도 계산, 이동, 렌더링, HUD, 미니맵
- `data.js` — 천체 제원, 궤도 요소, 대기, 착륙 지점, 밝은 별 목록
- `shaders.js` — 장면 및 별 하늘 셰이더
- `terrain.glsl.js` — 렌더링과 충돌 판정이 공유하는 지형 높이 함수
- `earth-data.js` — 생성된 지구 표면 지도 데이터
- `tools/build_earth.py` — `earth-data.js` 생성 스크립트

## 성능 구조

지표 근처에서는 여러 축척의 512×512 텍스처에 지형 높이를 구워 둡니다. 광선 행진과 그림자는 이 텍스처를 사용하고, 표면 색과 가까운 곳의 세부 지형을 계산할 때 절차적 노이즈를 평가합니다. 카메라가 이동하면 텍스처를 조금씩 갱신합니다. 부동소수점 텍스처 렌더링을 지원하지 않는 환경에서는 대체 경로를 사용합니다.

화면의 픽셀 비율을 최대 1.5배까지 반영하며, 기본 화질인 높음에서는 그보다 더 높은 해상도로 렌더링해 선명도를 높입니다. 느린 기기에서 부담이 커지지 않도록 GPU 시간에 따라 렌더 해상도를 자동 조절합니다. 화질 설정은 광선 행진과 대기 세부 수준도 함께 조절합니다. UI에는 Inter와 Noto Sans KR을 적용하고 시스템 글꼴을 대체 글꼴로 사용합니다. **H** 키를 누르면 프레임 속도, GPU 시간, 현재 해상도 비율을 볼 수 있습니다.

## 모델링 참고 사항

- 태양과 가스 행성에는 고체 표면이 없습니다. 태양은 광구를, 가스 행성은 1 bar 고도의 구름 꼭대기를 걸을 수 있는 표면으로 삼았습니다.
- 주요 지형은 직접 배치하고 세부 지형은 절차적으로 생성합니다. 달의 바다, 화성의 올림푸스 몬스와 마리네리스 협곡, 명왕성의 스푸트니크 평원 등을 포함합니다.
- 비행 속도는 광속을 넘을 수 있으며, Shift를 사용하지 않을 때 최대 약 0.1 AU/초입니다.
- 이동 범위는 약 120 AU 거리의 헬리오포즈 안쪽으로 제한됩니다.
